# Awesome POND [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

A curated list of open-source projects that fit the [POND Principle](https://www.pond.is/p/pond-a-human-machine-intelligence): AI that is **P**ersonal & Private, **O**n-Device & On-Premise, **N**odal & Networked, and **D**ecentralized & Distributed.

Want to add a project? See [CONTRIBUTING.md](CONTRIBUTING.md).

## Local inference
- [llama.cpp](https://github.com/ggml-org/llama.cpp) - LLM inference in C/C++ that runs on laptops, desktops and phones.
- [Ollama](https://github.com/ollama/ollama) - Download and run open models locally with one command.
- [Strata](https://github.com/Niko1221/Strata) - Runs very large mixture-of-experts models on a normal PC by splitting work across GPU, RAM and SSD.
- [vLLM](https://github.com/vllm-project/vllm) - High-throughput inference server for self-hosting open models.
- [MLX](https://github.com/ml-explore/mlx) - Array framework for running and training models on Apple silicon.
- [Transformers.js](https://github.com/huggingface/transformers.js) - Run Hugging Face models directly in the browser, no server.
- [WebLLM](https://github.com/mlc-ai/web-llm) - In-browser LLM inference accelerated by WebGPU.
- [LocalAI](https://github.com/mudler/LocalAI) - Self-hosted, OpenAI-compatible API for local models.

## On-device apps
- [Photokeeper](https://github.com/aritroCoder/photokeeper) - Extremely lightweight cross-platform app to manage and organize your photo gallery.
- [Lap](https://github.com/julyx10/lap) - Local-first desktop photo manager with private, on-device AI search.
- [MiniCPM-V Apps](https://github.com/OpenBMB/MiniCPM-V-Apps) - Offline multimodal chat apps for phones.
- [Open WebUI](https://github.com/open-webui/open-webui) - Self-hosted chat interface for local and remote models.
- [Jan](https://github.com/janhq/jan) - Desktop ChatGPT alternative that runs fully offline.
- [whisper.cpp](https://github.com/ggml-org/whisper.cpp) - Speech-to-text that runs locally on CPUs and phones.

## Personal agents
- [JERN](https://github.com/IshvaraX/JERN) - Self-hosted personal assistant on a fine-tuned 1.5B model, with tools that run on your own machine.
- [Hermes Agent](https://github.com/NousResearch/hermes-agent) - Open-source, self-improving personal agent from Nous Research.
- [OpenClaw](https://github.com/openclaw/openclaw) - Open-source personal AI assistant you run on your own devices.
- [Goose](https://github.com/block/goose) - Open-source, extensible on-machine AI agent.

## Peer-to-peer and federated
- [Petals](https://github.com/bigscience-workshop/petals) - Run large models collaboratively, BitTorrent-style, across many people's GPUs.
- [exo](https://github.com/exo-explore/exo) - Turn your everyday devices into one AI cluster.
- [Flower](https://github.com/adap/flower) - Framework for federated learning, where data stays on each device.
- [Nostr NIPs](https://github.com/nostr-protocol/nips) - Specs for the Nostr protocol, including NIP-90 data vending machines for agent jobs.

## Privacy and data ownership
- [Solid](https://github.com/solid/specification) - Specification for personal data pods the user controls.
- [Automerge](https://github.com/automerge/automerge) - CRDT library for local-first, sync-anywhere apps.
- [Immich](https://github.com/immich-app/immich) - Self-hosted photo and video backup with local ML.
- [Khoj](https://github.com/khoj-ai/khoj) - Self-hostable AI second brain over your own documents.
